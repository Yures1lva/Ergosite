# ErgoDay - Landing Page

Landing page para o ErgoDay, uma solução de IA que protege a saúde postural através de monitoramento ergonômico em tempo real.

## 📁 Estrutura do Projeto

```
Ergosite/
├── index.html          # Página principal
├── policy.html         # Política de privacidade
├── README.md           # Documentação
├── css/
│   ├── styles.css      # Estilos da página principal
│   └── policy.css      # Estilos da política de privacidade
├── js/
│   └── script.js       # JavaScript (tabs e smooth scroll)
└── images/
    ├── logo-ergoday-clock.jpg
    ├── logo-ergoday-spine.jpg
    └── logo-whatsapp.png
```

## 🚀 Como Usar

1. **Abrir diretamente:**
   - Clique duas vezes em `index.html`

2. **Servidor local (recomendado):**
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Node.js (com http-server)
```

## 🎨 Tecnologias

- **HTML5** - Estrutura semântica
- **CSS3** - Estilos modernos com variáveis CSS e gradientes
- **JavaScript Vanilla** - Funcionalidade de tabs e navegação suave

## 📱 Recursos

- Design responsivo
- Botão flutuante do WhatsApp com logo oficial
- Sistema de tabs para diferentes públicos (Empresas, RH, Colaboradores)
- Navegação suave entre seções
- Página de política de privacidade em conformidade com LGPD
- Seções otimizadas para SEO
- Favicon personalizado
